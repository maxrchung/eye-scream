# EYE SCREAM
This is a second-person puzzle platformer where you guide some characters to eat some ice cream from the point of view of some security camera eye things.

Made with Unity over a 3-day game jam.

## Play

I think because of our 16-and-a-half camera setup, the Unity web build basically doesn't work, but the Windows/Mac builds seem to be working fine. You can download them from: https://maxrchung.itch.io/eye-scream

## Controls

In camera grid view, left click to select a camera.

In camera view, WASD to move a character, left click + drag to turn the camera, right click to return to camera grid.

Allegedly this game supports controller, but I didn't work on that and don't know the controls for that so good luck.
